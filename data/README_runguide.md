# Data

- Refinitiv Datastream / Worldscope

- ECB Data Portal
- Wu–Xia shadow-rate series

Authorised users should place the final analysis panel here:

```text
data/processed/final_panel.csv
```

Do not commit this file. The repository's `.gitignore` excludes it.
